# Clock, tree, guest

CETI short explainer and instrument dashboard for the host/guest stack:

the browser event loop owns time, the DOM tree owns space, a compiled guest (Leptos / Wasm) sits on both, glue is the only test, and Jev is a judgment slot — not a clock.

Live: after Vercel link, the production URL is the project `ceti-clock-tree`.

- `#film` — eight-beat explainer (default)
- `#dashboard` — layer table, sites, glue tests

Brand follows [ceti-explainer](https://github.com/manutej/ceti-explainer): cream, vermillion, ink. No purple, no emoji headings.
